## Week 3 — 算法

### 二分查找

```
前提条件：数组必须有序
时间复杂度：O(log n)
```

我一开始不知道"有序"这个前提——如果数组无序，二分查找毫无意义。

### 排序算法

| 算法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 冒泡排序 | O(n²) | O(1) | 简单但慢 |
| 选择排序 | O(n²) | O(1) | 每轮选最小 |

## Week 4 — 内存

### 指针的正确用法 ⚠️（我答错过）

```c
// ❌ 错误：p未初始化就解引用
int *p;
*p = 42;  // 未定义行为！p指向垃圾地址

// ✅ 正确：先分配
int x;
int *p = &x;
*p = 42;

// ✅ 也可以动态分配
int *p = malloc(sizeof(int));
*p = 42;
free(p);
```

### malloc vs calloc

| 函数 | 功能 |
|------|------|
| `malloc(n)` | 分配 n 字节，**内容不确定** |
| `calloc(n, size)` | 分配 n×size 字节，**自动清零** |

### 内存泄漏

```c
// ❌ 泄漏
void leak()
{
    int *p = malloc(100);
    // 忘记 free(p);
}

// ✅ 正确
void no_leak()
{
    int *p = malloc(100);
    // 使用 p...
    free(p);
}
```

> 每条 `malloc` 都要配上一条 `free`——就像借了东西要还。

## Week 5 — 数据结构

### 链表

**优点**：不需要连续内存，插入/删除快（O(1)，如果已知位置）

**缺点**：不能随机访问（要找第 n 个元素得从头遍历 O(n)）

```c
typedef struct node {
    int value;
    struct node *next;
} node;
```

### 哈希表

用哈希函数把 key 映射到数组下标。

**冲突解决方法**（我只记得链地址法）：

| 方法 | 说明 |
|------|------|
| **链地址法** | 同一个桶挂一个链表，冲突了就链表上追加 |
| **开放地址法** | 冲突了就往后找下一个空位（线性探测等） |

## Week 6 — Python

### Python list vs C 数组

| | Python list | C 数组 |
|--|------------|--------|
| 元素类型 | 可以混合（`[1, "a", 3.14]`） | 必须同一类型 |
| 长度 | 动态增长 | 固定 |
| 越界 | 运行时抛异常 | 未定义行为 |

### try/except（异常处理）

```python
try:
    x = int(input("输入数字: "))
    print(f"你输入了 {x}")
except ValueError:
    print("请输入有效的数字！")
```

**执行流程**：
1. 先执行 `try` 里面的代码
2. 如果没出错 → 跳过 `except`
3. 如果出了指定类型的错 → 执行 `except` 里的代码
4. 如果出了未指定的错 → 程序崩溃
